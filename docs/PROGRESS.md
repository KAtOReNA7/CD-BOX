# CD-BOX Progress

## 2026-07-12 — 权威核验与封面硬门禁（本机日常使用版）

### 已锁定方向

- CD-BOX 只面向一个 owner，在 Windows 本机运行，不对局域网或互联网开放。
- 唯一运行入口是 `http://127.0.0.1:3000`；数据库是本机 PostgreSQL 16。
- 不提供注册、邀请、团队、角色或用户管理。
- 艺人与发行构成一个共享目录；用户关联表只保存 owner 的收藏状态和内部完整性信息。
- AI 使用现有 OpenAI-compatible 中转站的 `gpt-5.6-terra` Chat Completions。
- 联网发行只采用可追溯证据链：MusicBrainz 完整分页与 release-group 归并 → NDL Search 国家书目硬核验 → Discogs 辅助印证 → GPT-5.6 证据比较终审。
- Vercel 不参与运行、部署、数据库或 AI 路由；不新增云托管、云数据库、付费搜索 API、AI 路由或外部登录依赖。
- 所有秘密只保存在 Git 忽略且 ACL 受限的 `.env.local`；不得打印或提交。

### 已完成

#### 本机运行与安全

- 增加严格的本机 owner 模式，只接受数值回环 Host、Origin 和可信回环代理头组合。
- 启动脚本强制执行 `next start -H 127.0.0.1 -p 3000`。
- 完成 PostgreSQL 角色/数据库初始化、migration、生产构建、备份、SHA-256 校验和单事务恢复脚本。
- Bootstrap 可从 Windows 剪贴板安全读取现有中转站密钥，生成强随机数据库密码与认证秘密，并原子写入受保护的 `.env.local`。
- 完成旧数据导出文件到本机数据库的导入命令与事务边界。

#### 收藏工作流

- 完成艺人创建、艺人库、发行详情、来源管理、收藏状态、批量更新、筛选、统计与 Excel 导出。
- 完成 Excel 上传、预览、重复检测、跳过/更新/新建策略和确认导入。
- 保存来源 URL 到 `ReleaseSource`，保存真实封面 URL 到 `Release.coverImageUrl`。
- 导入与批量操作均具备事务边界和回归测试。

#### AI 与资料研究

- OpenAI-compatible 客户端支持 Responses 和 Chat Completions，并根据显式能力声明避免无效端点请求。
- 已验证当前 GPT-5.6 中转站的 Chat Completions 和 JSON 输出可用，Responses 正文与原生 web-search 不可用。
- 完成 MusicBrainz/Cover Art Archive 客户端：安全 URL、User-Agent、限速、有限重试、至多 500 行的完整分页、严格艺人消歧、release-group 归并、规范版本选择，以及响应内精确 CAA 封面发现。
- 完成 NDL Search 国家书目客户端与严格绑定：规范化品番必须唯一精确，艺人和共同日期精度必须一致；标题受控等值时直接通过，跨文字标题交给 GPT 保守终审，最终展示始终采用 NDL 权威本地标题。结果不完整、歧义、标识/日期冲突或服务不可用时不产生可导入结果。
- 完成 Discogs 匿名 API 辅助印证：只认日本 CD 的精确版本明细，校对标题、艺人、国家、格式、日期/年份、品番与强标识；无 NDL 的早期精确版本只能作为再版否决参考、不能进入结果；分页不完整时失败关闭。
- GPT-5.6 只接收压缩后的 MusicBrainz、NDL 与 Discogs 证据并逐条 `ACCEPT`/`REJECT`。模型不能浏览、补事实、改字段，也不能绕过确定性强证据门槛；不确定时必须拒绝。
- 完成封面级联：仅接受精确发行版 CAA 或精确 Discogs release 的 `primary` 图片；数字商店图片不作为实体版本封面。所有候选封面都经过 provider/最终主机绑定、受控重定向、完整受限下载、真实文件签名、MIME、尺寸与 Sharp 强制解码验证；截断图片不能通过。
- 未核验、证据冲突、歧义或无有效封面的条目自动隔离：不在正常艺人库或最终候选中展示，也不能导入；界面只报告归并与拒绝数量，不要求用户辨别。
- NDL 请求默认串行间隔至少 1 秒并缓存；Discogs 匿名请求默认串行间隔至少 2.5 秒，读取限速与 `Retry-After` 响应头。全局页脚及研究结果展示 NDL Search/CC BY 4.0 和 Discogs 数据/非隶属署名。
- 完成原文艺人名、候选选择/全选/导入和全过程进度提示；最终候选不可编辑，任何字段变化都必须重新搜索并核验。
- `rawResult` 保存研究模式、证据、响应、进度和脱敏错误。

#### 历史库核验

- `npm run library:verify` 只生成预览计划，不写数据库。
- 备份并审阅预览后，`npm run library:verify:apply` 只应用唯一匹配、证据完整且已有真实封面的结果。
- 脚本保留人工备注，不覆盖冲突的非空封面；无法核验的历史记录继续隔离。

#### 工程质量

- Next.js、React 和 Node/npm 版本已固定到当前安全版本范围。
- 完成 AI 协议、公共元数据、认证边界、导入事务、解析、质量门控、筛选、统计、导出和 Server Action 合约测试。
- 图片生成保持关闭；AI 生成图不能作为真实 CD 封面。
- 已移除不属于最终本机架构的云平台运行时依赖和配置。
